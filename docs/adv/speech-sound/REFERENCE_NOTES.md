# 会話音の参考調査

2026-10-30。市販ゲームの会話音を、文字表示に付く短い発声風の音として調査した。参考作品の ROM、サンプル、効果音は本作へ取り込まない。

この環境のモデルは音声入力に対応していない。以下は実際に取得した公開映像のフレームと音声データの波形・スペクトログラムによる確認であり、耳で聴いた評価ではない。BGM と効果音が混ざった音声なので、個々の会話音の正確な音高・長さを測定したとは主張しない。

| 資料 | 確認した範囲と方法 | 観察・設計への参考 |
|---|---|---|
| [ファミコン探偵倶楽部 PART II うしろに立つ少女・SFC版プレイ映像](https://www.youtube.com/watch?v=BxS_nu34Ozc) — Nintendo 公式チャンネル | 46 秒の公式映像。Wii U バーチャルコンソールの紹介枠内で SFC のゲーム画面を表示している。会話の文字送りをフレームで確認。19–27 秒の音声を波形・FFT で調べた。 | 文字の表示中に短い音のパルスがまとまり、間では途切れる。発音を長く持続させず、文字表示のまとまりと休止を作る参考とした。 |
| [EarthBound SNES Walkthrough Longplay](https://www.youtube.com/watch?v=m3JfATnXbqg) — PlayingWithMahWii、実況なし | 全 9 時間以上の動画のうち、6:00–6:30 だけ取得。移動、NPC との会話、場面の暗転を確認。取得区間の 12–19 秒を波形・FFT で比較。 | 会話表示の区間に短い鋭いパルス群と休止が見える。移動や暗転の音まで会話音と数えない。テキストが出ている間だけ音を発生させ、待ちで残さない設計の参考。 |
| [逆転裁判123 成歩堂セレクション・プロモーション映像](https://www.youtube.com/watch?v=UW6RfwjnJgI) — CapcomChannel | 106 秒の公式映像のうち 0:10–0:40 だけ取得。冒頭側に登場人物の文字送り、後半には宣伝用字幕がある。0:10–0:18 の音声を波形・FFT で調べた。GBA 版の録画ではなく、HD 版の紹介映像として扱う。 | 会話文と宣伝用字幕を区別した。音声には曲や演出音も含まれるため、純粋な文字送り音の音色や発音間隔は断定していない。 |

本作に採用する 20 数 ms の音、約 4 フレームの最短間隔、音量等は、本作の文字速度と落ち着いた推理 ADV の画面に合わせた独自の設計値であり、上の作品から抽出した値ではない。波形は正弦波の倍音、短い立ち上がりと減衰、軽い音高変化から新たに作り、BRR に変換して SPC700 で鳴らす。

参考映像・WAV・切り抜き画像は調査用のローカル一時ファイルに置き、配布 ROM、候補のソース一式、公開用の確認動画には含めない。取得ツールは公式 yt-dlp 2026.10.26 の SHA-256 を照合したもの。音声解析は 16 kHz、FFT 256、5 ms 刻みの波形とスペクトログラムで行った。聴感による自然さの確認は別の評価として残る。
