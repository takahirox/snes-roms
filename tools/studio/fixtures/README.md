# Chromatic Lab fixture

`demo/studio.json` is a standalone Studio v1 project. The demo's original geometric tiles, palettes, sample waveform and note sequences were created for Studio. They exercise transparency, nested flips, layers and metadata, sprite frames, glyphs, audio conversion and VRAM allocation. `paint.json` is a separate example transaction that edits one tile and places it on the demo map. The fixtures are dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
